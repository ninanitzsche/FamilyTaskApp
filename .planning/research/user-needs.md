# User Needs — FamilyBoard

## Context
Family of 4 (2 adults + kids 4 + 7), all diagnosed with ADHD.

## Personas
- **Parents**: Overwhelmed, need low friction, encouragement > task lists
- **Kids (4+7)**: Can't read, need images, motivation through gamification
- **Family Unit**: Needs coordination without nagging

## Core Features (MVP)
1. **Family Kanban Board** — Drag-and-drop, image-based
2. **Session Mode** — 5-min timer with music, choose 1-3 tasks
3. **Gamification** — XP, streaks, levels, screen time rewards
4. **Before/After Photos** — Visual motivation
5. **Weekly Missions** — 3 tasks per week as family challenge
6. **Encouragement-first Dashboard** — Shows what's done, not what's missing
