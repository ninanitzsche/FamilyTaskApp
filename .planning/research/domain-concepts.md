# Domain Concepts — Flight Levels for Families

## Adapted Flight Levels
- **FL1 (Individual)**: Personal task board per family member
- **FL2 (Family Coordination)**: Shared family board, sessions, coordination
- **FL3 (Goals)**: Weekly missions, family achievements, strategic outcomes

## Key Kanban Concepts (Family-fied)
| Concept | Corporate | Family |
|---------|-----------|--------|
| WIP Limit | Max 3 stories parallel | "Mama macht nur eine Sache" |
| Pull Principle | Dev pulls from backlog | "Hol dir eine Aufgabe wenn bereit" |
| Blocker | Blocked by API | "Keine Milch mehr da" |
| Swimlane | Per team/product | Per person |
| Board Design | Value Flow | Session → Done! |

## Core Principle for this App
**Session-First, not List-First.**
The app is built around 5-minute cleaning sessions, not traditional task lists.
Encouragement > accountability. Done > perfect.
