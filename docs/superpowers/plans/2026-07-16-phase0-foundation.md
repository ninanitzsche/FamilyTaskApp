# Phase 0: Foundation — Implementation Plan

**Goal:** Lauffähiges React + Firebase Projekt mit Auth, Navigation, Datenmodell und leerem Dashboard.

**Tech Stack:** React 19, TypeScript, Vite, Tailwind, daisyUI, Zustand, Firebase, vite-plugin-pwa, react-router-dom, lucide-react

## Tasks
1. Scaffold Vite + React + TypeScript project
2. Configure Tailwind + daisyUI + PWA
3. Firebase config + types + utils
4. Auth setup (Zustand store + hooks)
5. Layout components (AppShell, BottomNav, LoadingScreen)
6. Pages (Login, CreateFamily, Dashboard)
7. App.tsx + main.tsx + routing
